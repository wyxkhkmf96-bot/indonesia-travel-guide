The verdict

    Before departure

    出发前，把风险处理在家里

    不是泛泛的“注意安全”，而是按付款和出发时间排序的执行清单。

    01

    出票前

    • 先锁可退酒店和 Java 私人团，再买国际票。
    • 确认 D4 是 10/1；伊真 10/2 官方例行关闭。
    • 返程 LBJ→DPS 与 DPS→PVG 若分开出票，至少留 7 小时；不足就加住一晚。
    • 科莫多团确认快艇、救生衣、保险、园区费、取消条款。
    02

    提前 1—2 个月

    • 旅行医学门诊咨询疟疾、甲肝、伤寒等个人方案。
    • 保险需覆盖徒步、浮潜、医疗转运、行李和航班延误。
    • 伊真需 3 日内健康证明；心脏、哮喘、呼吸系统疾病不建议参加。
    • 只从印尼移民局官方入口办理 e-VOA。
    03

    出发前 72 小时

    • 查火山开放、BMKG 海况、航班状态；开放与否高于行程单。
    • 下载护照、保险、返程票、酒店、司机与船方联系人离线包。
    • 装备：防滑鞋、薄羽绒/防风层、N95、头灯、防水袋、驱蚊、补液盐。
    • 不要租摩托；跨岛陆路全程正规司机。
    04

    你们的水上规则

    • 水性一般：全程穿合身救生衣，先看水流再决定下水。
    • Manta Point 只在低流速、向导能照看三人时下水。
    • 不追蝠鲼、不离开小艇可见范围、不踩珊瑚。
    • 浪高、流急、能见度差、救生衣不合身——任一出现就留船上。
    三条绝不赌火山封闭不翻围栏科莫多出海当天不接飞机自转国际航班缓冲不低于 7 小时
