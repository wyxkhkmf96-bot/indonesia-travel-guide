01

09.27 · SUN

抵达东爪哇

上海浦东 → 短转机 → 泗水机场 → 市区酒店
主要项目
落地、休息、准备 Java 段

今天怎么走

  1. 上午
    上海浦东出发

    接受一次短转机，优先行李直挂；目标转机 2—4 小时、总时长 10—14 小时。

  2. 16:00—20:00
    抵达泗水

    入境、取行李、少量取现，预订司机在到达厅举牌接机。

  3. 落地后 90min
    入住，不再赶路

    酒店附近吃熟食，和 Java 包车方确认第二天 07:00 接车。

  4. 22:30 前
    整理瀑布装备

    防滑鞋、速干衣和防水袋单独装小包，主箱第二天留车上。

今晚住 · 两间房

Mövenpick Surabaya City

到达日优先睡眠和接车便利，不追求景区氛围。

约 ¥900—1,400 备选：Four Points by Sheraton Surabaya, Pakuwon Indah
当天注意

只买一张联程票。落地延误也不要继续赶四小时山路；泗水过夜是为了把第二天瀑布体力留足。

3 人当日预算¥1,100—1,800接机、餐饮与两间房
02

09.28 · MON

赛武瀑布大日

泗水 → Tumpak Sewu → Blue Cotton → 布罗莫
主要项目
观景台 + 峡谷徒步 + 瀑布群

今天怎么走

  1. 07:00
    泗水酒店出发

    早餐打包，专车前往赛武瀑布，预计 3.5—4.5 小时。

  2. 11:30
    赛武观景台 + 谷底

    先在上方看全景，再按天气和体力决定是否下谷；谷底约 2—3 小时。

  3. 14:30
    Blue Cotton

    水位安全、没有失温迹象才加走；天气转差则直接返回。

  4. 16:00—20:00
    前往布罗莫

    车程约 4 小时，途中吃晚饭；入住后不再安排夜游。

今晚住 · 两间房

Jiwa Jawa Resort Bromo

火山脚下的木石设计，第二天进入布罗莫更顺。

约 ¥1,600—2,400 备选：Plataran Bromo；预算型：Lava View Lodge
当天注意

峡谷台阶和水路很滑，只跟当地向导。暴雨、上游涨水或现场封闭时不下谷；手机必须进防水袋。

3 人当日预算¥1,400—1,900Java 团可能已含住宿与用车
03

09.29 · TUE

布罗莫火山

观景台 → 沙海 → 火山口 → 外南梦
主要项目
吉普穿越、沙海、火山口徒步

今天怎么走

  1. 07:00
    正常起床吃早餐

    不追日出，把全程唯一一次凌晨起床留给伊真。

  2. 08:30
    吉普进入布罗莫

    先走视野开阔的观景点，再进入沙海，避开日出后的车流高峰。

  3. 10:30
    步行至火山口

    按自己的节奏走台阶；风沙过大时戴 N95，不在护栏外拍照。

  4. 13:00—20:00
    横穿东爪哇去外南梦

    约 6—7 小时，途中完成午餐和晚餐，抵达后准备健康证明。

今晚住 · 两间房

Kokoon Hotel Banyuwangi

房间新、休息效率高，并可要求准备凌晨早餐盒。

约 ¥800—1,300 备选：Dialoog Banyuwangi（价格合适时升级）
当天注意

不骑无保护的马，不靠近火山口护栏。火山警戒升级或园区临时关闭时，直接改观景台行程。

3 人当日预算¥1,200—1,700吉普、门票、餐饮与 Java 团费用
04

09.30 · WED

唯一一次凌晨：伊真蓝火

外南梦 → 伊真 → 吉打邦 → 吉利马努克 → 洛维纳
主要项目
蓝火、火山湖、轮渡进入巴厘岛

今天怎么走

  1. 00:30
    酒店出发

    带健康证明、头灯、防滑鞋、保暖层和合格防毒面具。

  2. 02:00
    Paltuding 登山口进入

    全程跟向导慢走；蓝火区域能否进入，以当天风向和现场管制为准。

  3. 07:30
    下山、早餐、换衣

    洗脸并换掉带硫磺味的外层，补水后再开始跨岛移动。

  4. 10:30—16:00
    轮渡进入巴厘岛

    吉打邦到吉利马努克约 1 小时，再包车约 2.5 小时到洛维纳。

今晚住 · 两间房

The Damai Lovina

山景花园、环境安静，适合火山之后完整恢复。

约 ¥1,900—2,500 备选：The Lovina Bali Resort
当天注意

需要三日内健康证明。出现头晕、恶心、胸闷，或向导判断硫磺浓度和风向不利时立即折返。

3 人当日预算¥1,650—2,150向导、防护、轮渡、用车与住宿
05

10.01 · THU

北巴厘岛穿越

洛维纳 → 金塔马尼 → Leke Leke → 乌布
主要项目
火山景观午餐、轻徒步、酒店恢复

今天怎么走

  1. 09:00
    自然醒 + 酒店早餐

    不安排凌晨追海豚，让伊真之后的身体完整恢复。

  2. 11:30
    金塔马尼景观午餐

    选择正对 Batur 火山的餐厅；云层太厚则缩短停留。

  3. 14:30
    Leke Leke 瀑布

    往返约 60—90 分钟，路线比赛武轻松，但雨后仍需防滑鞋。

  4. 17:30
    乌布连住两晚

    入住后只安排酒店晚餐或 SPA，不再跨区移动。

今晚住 · 两间房

Dinara Ubud

绿意和室内设计兼顾，位置适合做两晚稳定基地。

约 ¥1,800—2,400 备选：Adiwana Unagi Suites（关注含税总价）
当天注意

今天的任务是恢复，不临时增加远距离景点。确认司机有休息时间；山路下雨时主动降低车速。

3 人当日预算¥950—1,500用车、门票、餐饮；酒店另计

10.02 · FRI

乌布行动日

乌布 → ATV 山谷 → Saba 黑沙滩 → 乌布
主要项目
ATV 山谷线、黑沙滩、SPA

今天怎么走

  1. 08:00
    早餐后出发

    不塞王宫和市场，把完整时间留给体验型项目。

  2. 09:30
    ATV 山谷线

    选择 90—120 分钟小团，穿包脚鞋和长裤，开始前试刹车。

  3. 13:00
    午餐 + 回酒店洗澡

    换掉湿衣，休息至少 1 小时，再安排下午活动。

  4. 16:00
    Saba 黑沙滩 + SPA

    海边只看景不下浪，晚餐后整理佩尼达一日小包。

今晚住 · 连住不换房

Dinara Ubud

继续住同一酒店，避免多一次收拾和搬运行李。

约 ¥1,800—2,400 第二晚应与首晚一起预订并确认同房连住
当天注意

ATV 必须提供全盔和保险，拒绝游客竞速、混行公路或车况明显不佳的运营商；黑沙滩浪大时不上水线。

3 人当日预算¥1,400—2,200ATV、SPA、用车与餐饮

10.03 · SAT

精灵坠崖与佩尼达西线

乌布 → Sanur → Nusa Penida 西线 → Sanur
主要项目
精灵坠崖、Broken Beach、可控浮潜

今天怎么走

  1. 06:20
    乌布出发去 Sanur

    主行李送当晚酒店寄存，提前 45 分钟到快船码头。

  2. 09:30
    Kelingking 精灵坠崖

    只在上方观景区域活动，不下陡坡去海滩。

  3. 11:30
    Broken Beach + Angel’s Billabong

    涨潮、大浪或护栏区域湿滑时，不进入天然池边缘。

  4. 14:00—17:30
    可控浮潜 + 返回 Sanur

    水流合适才下水；不抢最后一班船，回本岛后直接入住。

今晚住 · 两间房

ARTOTEL Sanur

有设计感，兼顾快船码头和第二天去机场的动线。

约 ¥1,700—2,400 备选：Akana Boutique Hotel
当天注意

精灵坠崖只看上方观景台。浮潜全程穿合身救生衣；水性一般时不离开向导和小艇可见范围。

3 人当日预算¥1,650—2,400快船、岛上包车、浮潜与餐饮

10.04 · SUN

飞往科莫多

Sanur → 巴厘岛机场 → Labuan Bajo
主要项目
境内飞行、海湾日落、出海确认

今天怎么走

  1. 08:30
    早餐 + 退房

    主行李正常托运，充电宝和贵重物品随身携带。

  2. 10:30
    提前 2.5 小时到 DPS

    境内航班也不压缩机场时间，给道路拥堵和托运行李留余量。

  3. 13:00—14:15
    DPS 直飞 LBJ

    优先不晚于 14:00 起飞的航班，发生延误仍有缓冲。

  4. 16:00
    入住 + 海湾日落

    和船方复核次日接车、救生衣、路线、园区费用及天气。

今晚住 · 两间房

Loccal Collection Komodo

白色阶梯建筑面向海湾，设计感和旅行氛围突出。

约 ¥2,100—2,500 备选：Sudamala Resort, Seraya（价格和接送合适时）
当天注意

必须搭上午或中午航班；当天不预订不能退款的日落船或正式出海项目，把航班延误风险留在缓冲日。

3 人当日预算¥1,050—2,400境内机票、接送和餐饮；酒店另计

10.05 · MON

科莫多主场

LBJ → Padar → Pink Beach → Komodo → Taka / Manta → LBJ
主要项目
火山日出地貌、粉沙、科莫多龙、浮潜

今天怎么走

  1. 05:50
    酒店接车去码头

    快艇小团约 06:30 出发，上船先检查救生衣和当天海况。

  2. 08:00
    Padar 登顶

    按体力停在中段或顶端，每人携带至少 1L 水，烈日下不硬撑。

  3. 10:30
    粉色沙滩 + 科莫多岛

    不带走沙子；进入园区后始终跟随 ranger，不跑、不蹲近拍。

  4. 14:00—17:00
    Taka Makassar / Manta Point

    只有低流速时才穿救生衣下水，返港后继续住一晚。

今晚住 · 连住不换房

Loccal Collection Komodo

出海后回到同一酒店，不接当晚飞机，也不搬运行李。

约 ¥2,100—2,500 返程航班安排在第二天，保留整夜天气缓冲
当天注意

看到蝠鲼是运气，下水是选择。强流、浪高、能见度差或救生衣不合身，任一出现就留在船上。

3 人当日预算¥2,600—4,300快艇、园区费、ranger 与午餐

10.06 · TUE

从科莫多直接回家

Labuan Bajo → Singapore → Shanghai
主要项目
开口程返沪，不再飞回巴厘岛

今天怎么走

  1. 起飞前 3H
    酒店退房去 LBJ

    在柜台再次确认行李能否直挂 PVG，保留两段登机牌。

  2. 白天
    LBJ 直飞新加坡

    周二优先使用 Scoot 班期；最终时间以出票页面为准。

  3. 目标 2—5H
    樟宜机场联程

    同一订单可接受短转；若需要入境取行李，则必须改成至少 7 小时。

  4. 夜间
    SIN 飞往 PVG

    不再返回巴厘岛，保险、登机牌和费用票据保留至回国。

今晚住

回到上海

返程只接受同一订单、行李直挂的联程组合。

不产生印尼住宿费 若无法组成联程，优先改经雅加达，不压缩分票转机
当天注意

订票页必须明确显示两段在同一订单。分票自转时，2—5 小时完全不够；不要用误机风险换几百元差价。

3 人当日地面预算¥300—600送机与餐饮，不含返程机票

Booking order

按这个顺序下单

01

先锁国际开口程

PVG→SUB 与 LBJ→PVG。三人总机票进入 ¥14,500—20,000 再下单。

02

再锁科莫多段

DPS→LBJ 选中午前后航班；科莫多快艇安排在返程前一天。

03

酒店全部选可取消

两间含税每晚不超过 ¥2,500，优先早餐、评分 8.5+、24 小时前台。

04

最后确认天气项目

伊真、佩尼达和科莫多均以开放状态、火山预警和海况为准。
